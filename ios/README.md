# Тело — трекер замеров

Минималистичный iOS-трекер замеров тела: вес, % жира, обхваты, графики и фото прогресса.
iOS 17+, SwiftUI, SwiftData, Swift Charts. Данные хранятся только на телефоне.

## Установка на iPhone (бесплатно, без публикации)

1. Установи Xcode из App Store и один раз открой его.
2. Открой `BodyTracker.xcodeproj`.
3. Xcode → Settings → Accounts → `+` → войди своим Apple ID.
4. Выбери таргет BodyTracker → Signing & Capabilities → Team: твой Personal Team.
   Если Xcode пишет, что bundle id занят, поменяй `com.vamorozov.bodytracker` на любой свой.
5. Подключи iPhone кабелем и выбери его вверху как устройство запуска.
6. На iPhone включи Настройки → Конфиденциальность и безопасность → Режим разработчика (телефон перезагрузится).
7. В Xcode нажми ▶︎ (Cmd+R).
8. На iPhone: Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять.

С бесплатным Apple ID подпись действует 7 дней. Когда приложение перестанет запускаться,
подключи телефон и снова нажми ▶︎ в Xcode. Данные при этом сохраняются.
