# Body

Минималистичный трекер замеров тела: вес, % жира и обхваты, графики прогресса, фото до и после.

Это веб-приложение (PWA). Оно ставится на домашний экран iPhone и работает офлайн.
Все данные хранятся только на телефоне, в IndexedDB. На сервере лежит только код.

**Открыть:** https://tovahasi.github.io/body-tracker/

## Установка на iPhone

1. Открой ссылку выше в **Safari**.
2. Нажми «Поделиться», затем «На экран Домой».
3. Запускай с иконки «Body».

## Бэкап

Всё во вкладке Log, внизу:

- **Export measurements** сохраняет все цифры в маленький файл. Делай его время от времени и сохраняй в Файлы или iCloud Drive.
- **Photo backup** показывает список месяцев. Нажми на месяц, затем:
  - **Save images** сохраняет фото обычными картинками в «Фото» или «Файлы»;
  - **Backup file** сохраняет файл, который можно импортировать обратно.
  Уже сохранённые месяцы помечены «Saved».
- Любое фото можно сохранить и отдельно, кнопкой «Поделиться» при просмотре.
- **Import from file** восстанавливает данные. Можно выбрать сразу несколько файлов: замеры и месяцы фото.

Если удалить иконку с домашнего экрана, данные удалятся вместе с ней. Из бэкапа их можно восстановить.

## Разработка

```
python3 -m http.server 8765
```

После изменений подними версию `CACHE` в `sw.js`, чтобы обновился офлайн-кэш.

В `ios/` лежит нативная SwiftUI-версия. Для работы она не нужна.
